## 2. Product Scope: What Core Cash Agent Should
## Own
The product should own decision intelligence, not full treasury infrastructure. It should connect to existing data
sources, apply treasury logic, and generate explainable next-best actions.
## Daily Cash Position Agent
Where are we today? Consolidated balances by entity,
bank, account and currency with stale/missing data
warnings.
## Forecast Intelligence Agent
Where will cash be in 7, 30 and 60 days? Uses AR, AP,
recurring flows, historical patterns and assumptions.
## Liquidity Risk Agent
What can go wrong? Flags shortfalls, concentration risk,
restricted cash issues and threshold breaches.
## Action Recommendation Agent
What should treasury do? Suggests transfer, funding,
collection follow-up, payment timing or escalation.
## Variance Explanation Agent
Why did actual cash differ from forecast? Identifies delayed
collections, early payments, fees, taxes or timing
differences.
CFO Summary Agent
What should management know today? Creates concise
daily executive cash update with risks and decisions
needed.
## Treasury Continuity Agent
What happens if the key treasury person is unavailable?
Preserves process memory, checklists and decision
rationale.
## Policy-aware Control Agent
What is allowed? Checks minimum cash, approvals,
restricted accounts, borrowing/investment limits and
cut-offs.
